# アイコン画像の置き場所

このフォルダに、決まったファイル名で画像を置くだけで、
評価登録フォームと評価カード画像の両方に自動的にイラストが反映されます。
DBへの登録やコード修正は不要です。

## 抽出方法（brew/）
- leaf.png … リーフ
- teabag.png … ティーバッグ
- pot.png … 手鍋
- powder.png … 粉末
- diluted.png … 希釈液
- unknown.png … 不明

## 添え物（accompaniments/）
- none.png … なし（ストレート）
- honey.png … 蜂蜜
- milk.png … ミルク
- sugar.png … 砂糖
- lemon.png … レモン
- ice.png … アイス（グラス）

## 画像の推奨仕様
- 形式: PNG（背景透過推奨）
- 比率: 正方形に近いもの（例: 128x128px 〜 256x256px）
- ファイルサイズ: 1枚あたり100KB以下を目安に

画像が用意できていない項目は、これまで通り文字のチップ表示のままになります
（一部だけ先にアップロードするのも可能です）。

# ホームのタイル用アイコン

ホーム画面の4タイル（HomePage）で使うアイコン。
ファイル名は home/page.tsx のタイルと対応している。

タブ用（`public/icons/nav/`）と同じ作法で描いている。
そちらの README も参照のこと。

- 太い輪郭（#3A2E1F）→ その外側に白いフチ（ステッカー風）
- 緑を基調に、濃淡で描き分ける
- 差し色は金（星）と紅茶色（カップの中身）のみ

## 各アイコン

| ファイル | 絵柄 | 備考 |
|---|---|---|
| rate | 星の付いたカップ | 緑タイルの上に載るため、カップ本体は生成りにして沈まないようにしている |
| shop | ピンの中にカップ | 地図で探すことを示す |
| points | スタンプカード | 2つ押印済み＋最後が金の星。ログインスタンプの見た目と揃えている |
| manual | 開いた本 | |

viewBox は 120×120。表示は34px程度なので、細部は潰れる前提で作ること。

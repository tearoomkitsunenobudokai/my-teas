# タブ用アイコン

上部メニュー（GridNav）で使うアイコン。ファイル名は GridNav.tsx の NAV 配列の
`icon` と対応している。

## デザインの方針（v397〜）

淹れ方・添え物アイコン（yotsuba氏）とは**意図的に別路線**にしている。
あちらは手描きの細い線と淡い色、こちらは太い輪郭・白フチ・ベタ塗りで、
役割が違うことが一目で分かるようにするため。

- 輪郭を太い濃色（#3A2E1F）で囲み、その外側に白いフチを回す（ステッカー風）
- 塗りはベタ。影は付けず、上面に白いハイライトだけ入れる
- **基調はアプリの緑（#1D9E75）**。濃淡を変えた緑で描き分ける

## 差し色を許しているのは3つだけ

全部緑にすると平坦で見分けが付かず、多色にするとアプリから浮くため、
次の3つにだけ緑以外を使っている。増やすときは理由を持たせること。

| アイコン | 差し色 | 理由 |
|---|---|---|
| certified | 金 | 表彰という意味が色そのもので伝わる |
| colors | 多色 | 色が並ぶこと自体がアイコンの意味 |
| contact | 暖色 | 緑一色だと reviews / print と形が紛らわしいため、色で切り分ける |

## 差し替えるとき

同じファイル名で置き換えるだけでよい。PNG にする場合は
`GridNav.tsx` の `iconSrc()` の拡張子を変える。

viewBox は 120×120。表示は最大48pxなので、細部は潰れる前提で作ること。
